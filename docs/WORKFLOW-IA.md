# Workflow de Desenvolvimento com IA — FutStore Brasil

1. **Contexto:** Consulte `docs/ARQUITETURA.md` antes de mexer em produtos, layout ou checkout.
2. **Tarefas Atômicas:** Separe alterações de catálogo (`produtos.json`), lógica de compra (`app.js`) e interface (`index.html` / `painel/index.html`).
3. **Validação:** Validar JSON (`produtos.json`) e sintaxe JavaScript (`node --check app.js`) antes de publicar.
